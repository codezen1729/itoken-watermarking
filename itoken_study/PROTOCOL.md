# Exact agreement of catalog-free logical-step IDs and survival after rewording

The design uses eight new public problems, 20 independent free-written candidate arguments per problem, six arguments per original, and one target and 199 independent surrogate 256-bit keys per problem. Two author agents wrote the problems’ arguments, blind pool readers extracted their advocated steps, and a separate author wrote 24 minimal logic contrast groups. No key is drawn before the code, representation, axes, weights, sources and primary endpoints are fixed. The target is never rerolled. The number of problems, threshold and output-selection rules do not change after the draw. Source indices are administrative and never given to recovery agents.

## Public representation

An independent agent reads the problem and prose, identifies any number of supported applications of reasoning and supplies a contiguous quotation per application. The public parser uses fixed English discourse connectives (for example “if”, “because”, and “so that”), punctuation, clause order and a short list of polarity markers. Without such markers the first sentence supplies the action field and any following sentences the outcome field. Unresolved fields are marked unspecified. This is a deterministic surface analysis with open vocabulary, not a complete logical grammar. The step fields and signed-action label from the reader are also retained to inspect its interpretation. For primary scoring, a fixed source-grounded parser derives the words in the evidence and three directed logical fields plus intervention polarity directly from the quotation. Thus two readers selecting the same evidence use the same normalization procedure. Evidence spans can differ; incomplete/ambiguous interpretations and collisions are possible. This procedure requires no reference passage, gold step, task-specific lexicon, desired count or candidate catalog at detection.

A pinned MiniLM sentence encoder embeds the evidence, premise, action and consequence. Three separate fixed signed coordinate permutations distinguish the written roles. Combine the four embeddings with coefficients 0.65, 0.35, 0.50 and 0.35 respectively, then normalize. Twelve fixed public thresholds on linear projections produce twelve candidate bits. On prior training topics we chose the shortest tested prefix (4, 5, 6, 7, 8 or 12 bits) with at most 5% within-topic wrong-step collisions for both original and rewritten readings. This selected five semantic bits. Prefix the intervention polarity bit to obtain a six-bit iToken. [Prior prefix calibration](prefix_calibration.json). The projection directions are learned once from previously published readings on six other topics. Two additional historical topics were used for development checks. This is an intentionally lossy code. Its 64 possible bit strings form a code space, with no list of allowed arguments or post hoc equivalence lookup. Rewording may alter even one bit. The full signature is required for exact iToken agreement.

A development prototype also encoded independently worded reader fields. Its historical results motivated the switch to deterministic evidence normalization before fresh keys. Published source quotes are part of the method; same-text agreement benefits from identical excerpts. Generalization requires testing rewritten evidence and close but logically different examples.

## Marking choices under real token probabilities

For each of 20 proposals the local Qwen2.5-0.5B-Instruct model supplies two single-token log probabilities for the same local usefulness question as in the preceding experiment. The base utility of a candidate is log P(Yes | Yes or No) plus a fixed per-candidate Gumbel shared by the three arms. The control maximizes average base utility. These are actual token probabilities for a local inclusion question. The authors’ probabilities for producing all possible next logical steps are unavailable.

Both keyed arms compare all eligible six-proposal subsets, maximizing mean base utility plus 12 times the unit-normalized keyed feature score. A proposal with no admitted steps is ineligible; require six. The exact arm counts complete iTokens. The tolerant arm uses 12 overlapping triples of bit positions, generated by cyclic shifts of (0,1,2) and (0,2,3) modulo 6. For each triple add seven to the observed pattern and subtract one for each of the other seven. Sum these features over supported steps. A problem-bound HMAC-SHA256 with the key, rule and feature identifier supplies a pseudorandom Gaussian via Box–Muller. The document score is the feature vector’s dot product with these values divided by its Euclidean norm. It is order-independent. No surrogate key enters the selector. Ties resolve lexicographically in source order. The control is scored under both rules. The two marked arms are separately generated and evaluated under the matching detector.

Each passage’s rank p-value is (1 + number of surrogate scores greater than or equal to the target score)/200. A reader flags the passage at p ≤ 0.01. No nonzero feature vector gives an abstention. The primary document call requires both independently extracted readings to be positive. Their votes share a key and must not be treated as independent statistical trials.

## Evaluation

Each original is joined in two paragraphs of three in source order; its arguments originate from a finite open sample. Each passage gets one free rewrite. Every original and rewritten document is independently read twice. A reader has only the public problem and one version, and each packet mixes arms with one passage per problem. Two other readers compare each original–rewrite pair directly, before any fresh detection ranks are inspected. Each returns preserved, changed or uncertain and a source-to-rewrite evidence mapping for research evaluation. Only two preserved votes count as faithful. The detector never sees the fidelity judgments or alignments.

Report plans, originals and rewrites out of all eight for each arm. Also report detections among all faithful rewrites and among faithful rewrites whose originals both readers flagged. An empty conditional denominator is undefined. The control row is calculated for each rule on the same control texts. Treat the findings as descriptive for these eight paired problems.

For exact agreement, align independently of bit values. Original source indices are determined by unique overlap of the reader’s cited span with a selected snippet. For rewrites both judges’ span mappings must agree on that index. The intersection must cover at least half the shorter span and exactly one anchor qualify. Duplicate, missing, ambiguous or split matches count as failures in the six-argument denominator. Report matches / attempted as primary, aligned denominators separately, and collisions between distinct aligned steps in the same document. Compare readers on the same original and same rewrite and across renderings with different readers. Pooled step counts reuse some selected arguments across arms. They are descriptive counts, not independent sample sizes.

The independent contrast test includes six polarity, six role, six mechanism and six condition/scope changes with original, faithful paraphrase and foil authored as a group. Separate readers receive one blinded text per group per packet. Exact success requires singleton codes equal; a singleton foil match is a false collision. Report unscorable/split cases, overall and by type. No similarity threshold substitutes for exact code equality, and detection under the tolerant rule does not establish equal iTokens.
